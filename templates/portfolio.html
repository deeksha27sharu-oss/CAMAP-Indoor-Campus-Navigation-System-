🎯 Campus Navigation System

An intelligent multi-floor navigation system for MLACW College that helps students, staff, and visitors find the shortest path between any two locations using Dijkstra's algorithm. Features include an AI-powered chatbot, voice navigation commands, real-time analytics, and support for 5 languages.

💡 Problem Solved

Large college campuses with multiple floors can be confusing for new students, staff, and visitors. This system eliminates the guesswork by providing real-time, optimized navigation between any two points on campus using proven graph algorithms.

🏆 Key Achievements

  • ✅ Implemented Dijkstra's algorithm for shortest path calculation
  • ✅ Integrated AI chatbot with natural language processing
  • ✅ Added voice commands using Web Speech API
  • ✅ Created interactive map with zoom and pan functionality
  • ✅ Built ML-powered analytics dashboard with traffic predictions
  • ✅ Multi-language support for 5 Indian languages
